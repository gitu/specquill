# Instant sync via push webhooks (deprecated)

**Deprecated 2026-07-24** with the removal of the GitHub integration: the
`/hooks/github` endpoint is gone. Interval polling (per-repo
`sync_interval`, 2-minute default for projects) and on-demand sync remain
the mechanism; if instant sync becomes a need again it should return as a
host-neutral webhook endpoint.

The original clauses live in this file's git history.
