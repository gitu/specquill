# GitHub-App tenants with derived authorization (deprecated)

**Deprecated 2026-07-24** by the single-tenant deployment decision: one
deployment per tenant (v1: customer OIDC; v2: developer-local) makes
in-process multi-tenancy and GitHub-derived authorization unnecessary.
Per-repository grants survive as [REQ-020](REQ-020.md).

The original clauses live in this file's git history.
