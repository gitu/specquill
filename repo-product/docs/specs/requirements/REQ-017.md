# GitHub sign-in with gated access and admin bootstrap (deprecated)

**Deprecated 2026-07-24** with the single-tenant deployment decision:
GitHub sign-in was removed. The driver ("use the accounts teams already
have") is met by the deployment model instead — v1 deployments authenticate
through the customer's own **OIDC** provider, v2 (developer-local) uses
**local accounts**; see [authentication.md](../specs/authentication.md).

The surviving non-GitHub clauses moved:

- provider negotiation (login page offers exactly what is enabled) —
  [authentication.md](../specs/authentication.md)
- admin bootstrap via `auth.admin_emails` (formerly REQ-017.4) —
  [authentication.md](../specs/authentication.md)
- secrets only via environment variables (formerly REQ-017.5) — unchanged
  across all config (`client_secret_env`, `token_env`).

The original GitHub clauses live in this file's git history.
